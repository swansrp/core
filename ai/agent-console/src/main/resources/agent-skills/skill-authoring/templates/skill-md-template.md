# SKILL.md 骨架（照抄改）

新建包的 SKILL.md 首部必须是 frontmatter，随后是给模型读的流程正文。
把下面骨架里的占位符换成实际内容；`name` 必须等于包的根文件夹名。

```markdown
---
name: 技能名（字母数字下划线连字符，且等于包根文件夹名）
title: 中文显示名
category: 分组，可省略
description: 做什么 + 何时触发，一到三句；这是模型默认唯一看得到的部分
---

# 技能标题

{一段话说清这个技能解决什么问题、产出什么。}

## 输入与产出

- 输入：{用户会提供什么}
- 产出：{产出物形态：结构、字段、格式}

## 执行步骤

1. {第一步，只引用已注册的工具名，不写 shell／脚本}
2. {第二步}
3. {……}

## 产出契约

- {结构、命名、日期格式、必填字段等硬性要求}
- {缺失信息怎么办：追问，不代填}

## 边界

- {这个技能不做什么}
- {不扩充工具权限}
```

## 目录形态

```text
技能名/
├── SKILL.md              # 必需
├── fields/               # 可选：字段清单
├── templates/            # 可选：产出骨架
└── examples/             # 可选：成品范例
```

## 命名与字符

- 根文件夹名与 `name` 只允许 `^[a-zA-Z0-9_-]+$`；中文显示名放 `title`，不放 `name`。
- 文件名可用中文（UTF-8 打包），但目录层级保持浅，便于按需读取。
