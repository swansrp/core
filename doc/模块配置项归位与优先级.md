# 模块配置项归位与优先级（yml ↔ sys_config 逐键明细）

一句话规则：**环境绑定的值（地址/账号/口令/Key/代理）与"切了会让历史读错路"的键只进 yml；运行期该热调的阈值/开关进 sys_config 参数页；两处同名的键，取值链一律＝库值非空白优先 → yml 回落 → 出厂缺省**（库值留空＝"未表态"，不是"关闭"）。

> 键面正源＝core 各模块 `*-config.template.yml`＋`*ConfigTemplateCoverageTest`（yml 侧）与 `@MetaParam` 枚举（参数页侧），本文逐键表 2026-10-21 从源码实读核对；与 project-setup skill `assets/module-docs/` 同步维护。
> "位置"列含义：**yml**＝只在配置文件；**参数页**＝只在 sys_config；**两处**＝同名共存、库值优先。
> 🔴 sys_config 行的 config_key＝**枚举名本体**（如 `BASE_URL`、`OSS_SERVER_TYPE`），按 `@MetaParam("分组名")` 列分族展示——`LLM` 族的 `BASE_URL` 与 `AGENT_RUNTIME_BASE_URL` 是两个不同键，读键时先认族。
> 参数页键改动**即时生效、不用重启**（除注明"重启/缓存刷新"者）；yml 键改动一律要重启。

## 一、llm（大模型接入）

读取点单源＝`DbAwareModelConfigProvider`（库值→yml 回落）。

| 键 | 位置 | 出厂/缺省 | 能填什么 · 填了是什么意思 |
|---|---|---|---|
| 大模型服务地址（参数页族"大模型" `BASE_URL`） / yml `llm.base-url` | 两处 | 空 | OpenAI 兼容端点 URL（通常含 `/v1`）。🔴 库值一旦填了会顶掉现场 `.env`/yml 地址；留空＝按 `llm.base-url`；改后下一次调用即用 |
| 大模型密钥（族 `API_KEY`） / yml `llm.api-key` | 两处 | 占位 `sk-****`（含 `*` 视为未填） | 真实密钥只在参数页手填；yml 侧走 `${LLM_API_KEY:}` 占位。⚠️ 敏感值 |
| 默认模型名（族 `MODEL_NAME`） / yml `llm.model-name` | 两处 | 空 | 模型名（供应商控制台可查）；留空＝按 yml；临时换模型改这格、不重启 |
| `llm.timeout-seconds` | yml | `120` | 正整数秒；普通调用超时，慢模型调大；参数页 `大模型超时(秒)` 非法值回落到它 |
| `llm.agent.timeout-seconds` | yml | `600` | Agent 编排单次调用上限秒数；参数页键非法值回落 |
| `llm.vision.base-url` / `api-key` / `model-name` | yml（另有参数页同款三键回落） | 空 | 视觉模型三格；不用扫描件/图片解析就整段留空；`VISION_MODEL_NAME` 须填支持图片输入的模型（如 qwen-vl-max），留空会回落默认模型⇒多半解析失败 |
| `llm.vision.timeout-seconds` | yml | `180` | 图片转录耗时长故高于文本档 |
| `llm.agent-session.key-prefix` | yml | `llm:agent:session:` | Redis 键前缀，多应用共用一套 Redis 时才需要改 |
| `llm.agent-session.ttl-seconds`（参数页 `AGENT_SESSION_TTL_SECONDS`） | 两处 | `86400`（24h） | 会话快照在 Redis 活多久；库值留空＝按 yml。⚠️ 只影响之后的写入，活跃会话每次写入续期，实质＝最后一次写入后的静默时长 |
| `llm.agent-task-gate.key-prefix` | yml | `llm:agent:task-gate:` | 任务门锁键前缀 |
| `llm.agent-task-gate.orphan-millis`（参数页 `AGENT_TASK_GATE_ORPHAN_MILLIS`） | 两处 | `90000`（90s） | 属主心跳超此毫秒判失联、强删锁自愈。🔴 调小于任务心跳间隔＝把在跑的任务误判失联造成双跑 |
| `llm.stream-answer.key-prefix` / `ttl-seconds` / `finished-ttl-seconds` / `min-write-interval-ms` | yml | `llm:stream:answer:` / `600` / `300` / `300` | 流式答案 Stream 前缀/存活/完成后保留/写入节流毫秒 |
| `llm.streaming.idle-timeout-ms` / `max-wait-ms` | yml | `15000` / `3600000` | SSE 空闲超时/单流最长等待 |
| `llm.chat-sse.enabled` | yml | 演示端点开关 | demo 用，生产可关 |
| `llm.proxy.enable` / `host` / `port` | yml | `false`/空/`0` | 出网代理三键；`enable: false`＝直连零行为变化，true 时 host 必填 |
| 工具结果卸载阈值 `AGENT_TOOL_RESULT_OFFLOAD_CHARS` | 参数页 | `0` | 🔴 **开关键**：0＝不卸载（原行为）；正值（建议 4000）起，超长工具结果入场替换为预览＋句柄，原文经过程事件流按句柄回捞 |
| Agent 上下文 token 预算 `AGENT_CONTEXT_TOKEN_BUDGET` | 参数页 | `0` | 🔴 **开关键**：0＝仅按条数裁窗；正值（建议 24000）＝进模型消息估算 token 上限，与条数取更严（估算偏保守宁可早裁） |
| 卸载预览字数 `AGENT_TOOL_RESULT_PREVIEW_CHARS` | 参数页 | `1000` | 🔴 **闸门键**：头尾预览合计字（头 8 成尾 2 成）；填 0/非法＝回落 1000（**不是关闭**，关闭请置卸载阈值 0） |
| 回捞次数上限 `AGENT_TOOL_RECALL_MAX_PER_RUN` | 参数页 | `3` | 闸门键；0/非法回落 3；超限只提示收口、防轮次爆炸 |
| 回捞返回上限 `AGENT_TOOL_RECALL_MAX_CHARS` | 参数页 | `20000` | 闸门键；单次回捞回填模型的原文字上限，超出截断（全文仍在前端过程树） |
| 回捞缓冲容量 `AGENT_TOOL_RECALL_BUFFER_CHARS` | 参数页 | `120000` | 闸门键；run 作用域可回捞总字数，超出按插入序挤掉最旧句柄 |

## 二、agent-runtime（外部 Agent 平台接入）

读取点单源＝`AgentRuntimeConfigProvider`（每 getter 实时算）。

| 键 | 位置 | 出厂/缺省 | 能填什么 · 填了是什么意思 |
|---|---|---|---|
| `my.agent.runtime.enabled` | yml | **`false`＝不装配** | 必须显式 `true` 才出 `/web/agent/rt/**` 端点——"依赖进来了但静默没接"的现场最难查形态 |
| `my.agent.runtime.provider` | **仅 yml** | **`openhands`** | 二选一：`openhands`（缺省正源，键不写也走它）/ `agent-system`（legacy 腿＝自研 py 平台，须显式配置才生效）。🔴 刻意不进参数页：切换会让已登记会话历史读错路，必须重启 |
| 平台服务地址 `AGENT_RUNTIME_BASE_URL` / yml `…base-url` | 两处 | 空 | 开放面 http 地址（openhands＝agent-server 如 `http://127.0.0.1:13100`）；两处都空＝未接线（调用时才报错） |
| 平台密钥 `AGENT_RUNTIME_API_KEY` / yml `…api-key` | 两处 | 占位 `sk-****` | 🔴 这是**平台凭据不是模型凭据**：缺省 openhands＝会话密钥（`X-Session-API-Key`，只准入、不认业务身份，对应上游 `OH_SESSION_API_KEYS_0`）；显式 `agent-system` 才是 `sk-rt-` 平台密钥。跑哪个模型由上游容器 env 决定，本模块管不到 |
| 接口前缀 `…API_PREFIX` / yml `…api-prefix` | 两处 | `/open/v1` | 仅 `agent-system` 用到；openhands 走自己的 agent-server REST 面、忽略本键 |
| 连接超时 ms / 单轮空闲超时 ms | 两处 | `5000` / `120000` | 空闲超时＝上游单轮流多久无数据判断流；🔴 勿低于 60 秒（平台 15 秒心跳，留 4 倍余量） |
| 中转心跳秒 / 中转线程数 | 两处 | `15` / `32` | 心跳防反代断连；每活跃轮占 1 线程＋1 条上游连接，并发大调线程数 |
| `my.agent.runtime.workspace-root` | yml | `/workspace` | 仅 provider=openhands 生效，会话工作区根 |
| `my.agent.runtime.agent-profile` | yml | `default` | 建会话引用的上游 profile；🔴 上游 profile 库不随镜像走，缺 `default`＝建会话全体 404（zz 10-20 实踩，InkHub 已收进 deploy.sh `oh-profile` 腿） |
| `my.agent.runtime.max-iterations` | yml | `30` | 单轮最多工具调用步数＝防跑飞成本上限；成本敏感调小 |
| `my.agent.runtime.proxy.*` | **仅 yml** | `false`/空/`0` | core→runtime 出网腿代理；刻意不进参数页（部署档＋避免代理主机在管理页露面） |

## 九、其余参数页专属小族（@MetaParam）

## 十三、为什么这样切＋落盘纪律

- **只留 yml、刻意不进参数页的两类**：① 环境绑定项（密钥、代理主机——不该在管理页露面）；② 切换会让已有会话/历史读错路的键（如 `provider`，必须伴随重启）。
- **进 sys_config 的判据**：运营期要热调、且改错不炸链路。core 种子按枚举缺省回种——**只插不删**，改缺省救不了已建库，所以出厂值一律留空＝未表态（例外：占位符 `sk-****`、后门开关等以"含 `*` 视为未填"或显式缺省表达）。
- **两类 0 语义别混**：开关键 0＝关闭机制（卸载/token 预算/思考强度）；闸门键 0/非法＝回落保守默认、**不是关闭**（预览字/回捞三键/超时）。kafka `max-topic-retry-attempts: 0`＝无限重试，是第三种语义。
- 🔴 **profile 落点**：开关/模式/安全语义类键写进部署实际生效的 profile（通常 `application-pre.yml`，用 prod 再写一份）——只写 dev 等于部署档没配。
- 🔴 **敏感值形态**：yml 一律 `${KEY:}` 占位；core 模板真值放 `server/.env`（git 排除、relaxed binding），framework 型无 `.env`、由 Jenkins/启动参数注入同名环境变量。`.env` 键名规则＝属性路径 `.`/`-` 全换 `_` 再大写，写错**静默不生效**。
- 🔴 **同名共存键的读取点必须单源**（`DbAwareModelConfigProvider`／`AgentRuntimeConfigProvider`／`OssServiceSelector`／`LoginServiceImpl#resolveRegisterMode`）——同一进程两条腿各按各的选型读＝事故。
- **agent-console 零 yml 配置面**：运行参数全走 llm 的 LlmParam 族。
